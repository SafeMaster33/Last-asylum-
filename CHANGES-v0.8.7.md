# v0.8.7-test

- Неопределённый результат обратного свайпа больше не приводит к немедленной остановке.
- При неопределённости выполняется укороченный горизонтальный жест (20% ширины экрана), затем новая проверка изображения.
- Отсутствие измеренного сдвига не считается подтверждением границы.
- После шести неуспешных циклов восстановление останавливается безопасно без перехода вниз.
- В журнал добавлены отправка и завершение жестов.
- Вертикальный переход по-прежнему выполняется только после подтверждённой границы.

Ограничение: при динамической карте алгоритм сопоставления кадров может не определять направление сдвига. Это диагностическое исправление, а не гарантия полного обхода.
