# Last Asylum Scanner v0.4

- Три режима поиска: имя+уровень, только уровень, только имя.
- При поиске по имени и уровню OCR отметки уровня запускает жест увеличения двумя пальцами и проверку имени; затем попытку возврата масштаба.
- Переход на следующую полосу после трёх подряд проверок отсутствия горизонтального смещения; три попытки спуска перед остановкой.
- Настройки сохраняются между запусками.
- Добавлен gradle.properties с android.useAndroidX=true.

## Ограничения
Не проверено на реальном устройстве. OCR уровней может путать цифры с элементами интерфейса, а увеличение может сместить объект из области видимости. Порог движения эвристический и не доказывает достижение границы. Поиск не гарантирует полного охвата карты. Если игра не поддерживает жест масштабирования, проверка имени не сработает. После остановки при увеличенном масштабе может потребоваться вручную уменьшить карту. Исходный архив не содержит gradlew/gradle-wrapper.jar; собирайте из AndroidIDE или установленным Gradle с JDK 17.
