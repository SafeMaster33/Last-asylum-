# Last Asylum Scanner v0.9.0-test

Экспериментальная доработка обработки плотных скоплений объектов.

- После увеличения карты очередь координат сбрасывается; кандидаты ищутся заново на восстановленном обзоре.
- Проверка кандидата выполняется увеличением вокруг его позиции, без отдельного центрирующего свайпа.
- Установлен предел попыток проверки одного кандидата; неподтверждённый кандидат отмечается и пропускается.
- Увеличение и уменьшение выполняются относительно одной точки, чтобы уменьшить дрейф карты.
- Упорядочивание кандидатов сверху вниз и слева направо.
- Повышена версия APK до 0.9.0-test.

ОГРАНИЧЕНИЯ:
- OCR по-прежнему латинский ML Kit. Полноценная кириллица НЕ реализована: для неё нужен отдельный Android-совместимый OCR с русской моделью.
- Координаты и возврат масштаба требуют проверки на реальной карте.
- Сборка не проверена в этой среде (Android SDK/Gradle отсутствуют).
- Навигация змейкой намеренно не изменялась.
