# Last Asylum Scanner v0.6 (экспериментальная)
- Полупрозрачная перетаскиваемая кнопка поверх игры (TYPE_ACCESSIBILITY_OVERLAY), запуск и остановка.
- Параметры задержки после свайпа и количества повторных попыток.
- Последовательная очередь найденных уровней на текущем снимке.
- Проверка сходства изображения до/после восстановления масштаба; при большой разнице остановка для ручной калибровки, чтобы не продолжать поиск на неверном масштабе.

## Ограничения
- Сходство изображения — эвристика, а не точное измерение масштаба: анимация и движение карты могут приводить к ложным остановкам. Автоматического определения масштаба пока нет.
- Автоматическое открытие профиля не реализовано.
- Проверка имени в текущем OCR-алгоритме ищет текст в центральной области, а не строго рядом с базой.
- Установка поверх версии с иной подписью может быть невозможна без удаления старой версии (сохраните данные заранее).
- Архив содержит исходники, не скомпилированный APK. Для сборки нужен AndroidIDE, Java 17, Gradle 8.9 и Android SDK.
