# v0.7 — тестовый исходный проект

Изменения: OCR-кандидаты теперь требуют расположенной непосредственно над уровнем подписи базы. Это отсекает многие ресурсы и мобов без имени, но не гарантирует исключение всех сооружений. При читаемом никнейме увеличение пропускается. Добавлены центрирование цели и небольшие последовательные жесты увеличения с повторным OCR. При неподтверждённом горизонтальном движении сканер останавливается вместо автоматического перехода вниз (безопасная временная мера).

Ограничения: автоматическая классификация синих/красных/белых баз ещё НЕ реализована; цветовой фильтр не включён. Надёжное восстановление положения камеры после центрирования также НЕ реализовано. Точное обнаружение границы и автоматический переход на следующую полосу требуют отдельной разработки. Протестируйте на копии проекта.

Сборка: в AndroidIDE в корне проекта восстановить wrapper из кэша Gradle 8.9, использовать Java 17 и выполнить ./gradlew clean assembleDebug --no-daemon.
