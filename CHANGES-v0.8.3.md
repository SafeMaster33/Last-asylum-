# v0.8.3 — безопасная диагностика навигации

- Режим 3 горизонтальных + 1 вертикальный свайп, без OCR.
- Сохраняются реальные JPEG-кадры до и после каждого жеста в app-specific external files/navigation_<timestamp>.
- Запрет перехода вниз при неподтверждённой горизонтальной границе.
- Журнал сохраняет текущие показатели смещения; значения uncertain не считаются движением.
- Полноценный поиск по змейке НЕ заявлен исправленным: для него требуется проверенный метод определения границы и положения.
- Файлы диагностики могут содержать изображение игрового экрана. Перед передачей проверьте их.
