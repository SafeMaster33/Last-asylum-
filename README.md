# Last Asylum Scanner v0.1 — исходный проект

Откройте папку в Android Studio (JDK 17, Android SDK 35), дождитесь Gradle Sync и выберите Build > Build APK(s). Установите app-debug.apk на Android 11+.

1. Запустите приложение, включите его службу в «Специальных возможностях».
2. Введите никнейм и уровень. Нажмите «Запустить» и откройте карту игры до первого снимка (примерно 1,2 с).
3. Приложение снимает экран, распознаёт надписи, делает свайпы и останавливается при двух совпадениях подряд.
4. Для экстренной остановки откройте приложение и нажмите «Остановить» или отключите службу в настройках Android.

## Ограничения прототипа
- APK здесь не собран: поставляется проект для Android Studio. Компиляция и работа на реальном телефоне не проверены.
- OCR требует доступности ML Kit; первоначальная установка зависимости выполняется через Gradle.
- Привязка уровня к никнейму — эвристика по координатам, может требовать настройки под экран.
- Вариант v0.1 не записывает игровые координаты, не сохраняет снимки и не имеет плавающей кнопки остановки.
- Маршрут «змейка» приблизительный: игра может ограничивать карту, а горизонтальные проходы не гарантируют полного покрытия.
- Android может ограничивать скриншоты защищённых окон; игра может запрещать автоматизацию своими правилами.
- OCR длинных никнеймов может ошибаться, поэтому совпадение пока строгое.
- Приложение не атакует игроков, не использует сетевые API игры и не отправляет данные наружу.


## Изменения v0.2
- Начало сканирования: пользователь вручную позиционирует карту в верхнем левом углу нужной области; автоматического определения границы мира нет.
- При двух последовательных OCR-совпадениях сканирование останавливается, включается звук (ToneGenerator) и вибрация.
- Для вибрации добавлено разрешение VIBRATE.
- Важно: запуск из Activity требует быстро вернуться в игру; автоматического возврата в игру нет.
- Прототип не проходил сборку и проверку на реальном устройстве.
