# Last Asylum Scanner v0.9.2-test

Тестовая версия для Android 11 и новее, versionCode 20. Продолжает v0.9.1-test на основе `SafeMaster33/Last-asylum-`, коммит `676cef6`. На главном экране и при запуске поиска в журнале отображается версия установленного APK.

## Сборка в Android IDE

Распакуйте архив в `/storage/internal_new/project/LastAsylumScanner-v0.9.2-test-source`. Внутри появится папка `LastAsylumScanner` с файлом `settings.gradle.kts`. Команды рассчитаны на Gradle 8.9, JDK 17, Android SDK 35 и AAPT2 в `/usr/bin/aapt2`.

```sh
project=/storage/internal_new/project/LastAsylumScanner-v0.9.2-test-source/LastAsylumScanner
export JAVA_HOME=/opt/java/jdk-17.0.21.1+2
export PATH="$JAVA_HOME/bin:$PATH"
/storage/internal_new/project/gradle-8.9/bin/gradle -p "$project" :app:testDebugUnitTest :app:assembleDebug &&
/usr/bin/aapt2 dump badging "$project/app/build/outputs/apk/debug/app-debug.apk" | grep '^package:'
```

Готовый APK появится в `app/build/outputs/apk/debug/app-debug.apk`. При первой сборке Gradle понадобится доступ к репозиториям зависимостей. Обе языковые модели включены в проект. На телефоне OCR работает локально.

## Что проверить на карте

1. Включите службу специальных возможностей. В поле «Искать по» выберите «Имени и уровню», задайте полный ник и уровень, нажмите «Сохранить для плавающей кнопки». Вернитесь на карту и нажмите плавающую кнопку старта.
2. На дальнем обзоре выберите «Масштаб карты» → «Увеличивать для чтения имени». При варианте «Сохранять текущий масштаб» сканер может сдвигать карту, чтобы вывести подпись из-под панели. Для поиска только по уровню попробуйте на дальнем обзоре уровень 15 с белой меткой базы. После обновления уже сохранённый выбор масштаба сохраняется.
3. На плотном участке проверьте две соседние базы одного уровня. При поиске по имени и уровню подтверждение требует двух последовательных чтений нужного ника возле значка одной базы. Если исходный обзор восстановить не удалось, причина остановки появится в журнале поиска.
4. Для отдельной проверки кириллицы выберите «Имени» и введите `пивомен` без тега альянса. Для проверки движения карты откройте «Дополнительные настройки» и включите «Диагностика навигации» (3+1).

Сканер повторно читает мелкие плашки в двух вариантах контраста. После жеста он измеряет смещение деталей карты и проверяет, какой свежий значок соответствует базе. При потере значка после увеличения прогноз позиции можно использовать для чтения имени. Положительный результат требует двух совпадений. После подтверждённого возврата одиночный неразобранный объект учитывается в журнале, а обход продолжается. Если положение карты восстановить не удаётся, сканер останавливается.

Видеопроверка проводилась на портретной записи 720×1600. В журнале диагностики 3+1 проверяется только движение карты. Для поиска цели отключите этот режим. После сборки проверьте в выводе AAPT2 `versionName='0.9.2-test'` и `versionCode='20'`, затем установите новый APK.

## Первоначальная версия v0.1

Откройте папку в Android Studio (JDK 17, Android SDK 35), дождитесь Gradle Sync и выберите Build > Build APK(s). Установите app-debug.apk на Android 11+.

1. Запустите приложение, включите его службу в «Специальных возможностях».
2. Введите никнейм и уровень. Нажмите «Запустить» и откройте карту игры до первого снимка (примерно 1,2 с).
3. Приложение снимает экран, распознаёт надписи, делает свайпы и останавливается при двух совпадениях подряд.
4. Для экстренной остановки откройте приложение и нажмите «Остановить» или отключите службу в настройках Android.

## Ограничения прототипа
- APK здесь не собран: поставляется проект для Android Studio. Компиляция и работа на реальном телефоне не проверены.
- OCR требует доступности ML Kit; первоначальная установка зависимости выполняется через Gradle.
- Привязка уровня к никнейму — эвристика по координатам, может требовать настройки под экран.
- Вариант v0.1 не записывает игровые координаты, не сохраняет снимки и не имеет плавающей кнопки остановки.
- Маршрут «змейка» приблизительный: игра может ограничивать карту, а горизонтальные проходы не гарантируют полного покрытия.
- Android может ограничивать скриншоты защищённых окон; игра может запрещать автоматизацию своими правилами.
- OCR длинных никнеймов может ошибаться, поэтому совпадение пока строгое.
- Приложение не атакует игроков, не использует сетевые API игры и не отправляет данные наружу.


## Изменения v0.2
- Начало сканирования: пользователь вручную позиционирует карту в верхнем левом углу нужной области; автоматического определения границы мира нет.
- При двух последовательных OCR-совпадениях сканирование останавливается, включается звук (ToneGenerator) и вибрация.
- Для вибрации добавлено разрешение VIBRATE.
- Важно: запуск из Activity требует быстро вернуться в игру; автоматического возврата в игру нет.
- Прототип не проходил сборку и проверку на реальном устройстве.
