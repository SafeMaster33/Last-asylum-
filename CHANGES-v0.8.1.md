# Last Asylum Scanner v0.8.1-test — исправление навигации

- Вместо фиксированного порога 6,5% изменения цвета используется поиск пространственного смещения изображения между скриншотами.
- Если результат сравнения неоднозначен, поиск останавливается с диагностикой, а не объявляет достижение края карты.
- При подтверждённом отсутствии горизонтального движения после успешных перемещений предпринимается переход вниз.
- Вертикальный свайп изменён с 35% до 50% высоты экрана, чтобы уменьшить пропуски между ярусами; величина требует проверки на конкретном устройстве.
- После подтверждения перехода на следующий ярус направление меняется, счётчик подтверждённых шагов сбрасывается.
- В журнал выводится оценка смещения и исходная разница изображений.
- Версия не гарантирует распознавание истинной границы карты: визуально однообразная местность и анимации могут приводить к неоднозначным измерениям. Это тестовая сборка.
- Android Gradle Plugin 8.7.3, Kotlin 2.0.21, Java 17, Gradle 8.9: конфигурация оставлена без изменений.

## Сборка в Android IDE

```
cd /storage/internal_new/project/LastAsylumScanner
export JAVA_HOME=/opt/java/jdk-17.0.21.1+2
export PATH="$JAVA_HOME/bin:$PATH"
/storage/internal_new/project/gradle-8.9/bin/gradle assembleDebug
```

APK: app/build/outputs/apk/debug/app-debug.apk

Внимание: версия в AndroidManifest/Gradle повышена до 9, versionName=0.8.1-test.
