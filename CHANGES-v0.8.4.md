# v0.8.4-test

- Проверка предполагаемой горизонтальной границы обратным свайпом и подтверждением возврата.
- Переход вниз и смена направления только после успешного обратного и возвратного свайпов и подтверждения вертикального перемещения.
- Неопределённые кадры не считаются доказательством границы.
- Диагностика по умолчанию отключена при новой установке; настройки сохраняются.
- Важно: это экспериментальная версия. Сравнение кадров может давать ложные результаты; при неопределённости сканер останавливается без заявления о полном обходе.
