# v0.8.2 — диагностика навигации

- Режим диагностики по умолчанию: три горизонтальных свайпа и один вертикальный, без OCR и поиска.
- Неоднозначное смещение не трактуется как край карты или подтверждённое движение.
- Журнал выводит классификацию движения, разницу кадров и оценку совпадения.
- В обычном режиме неоднозначный кадр перепроверяется без нового жеста (до трёх раз).
- Полный обход карты пока не гарантирован; текущая версия предназначена для измерения работы жестов на реальной карте.
- Сохранены настройки сборки AGP 8.7.3 / Kotlin 2.0.21 / Java 17 / Gradle 8.9.
